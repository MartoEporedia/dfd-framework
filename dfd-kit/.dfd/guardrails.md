# Guardrail del progetto DFD Kit

- Data: 2026-10-09
- Owner: manutentore del repository

Il progetto adottato è `dfd-kit/`; gli artefatti sono in `.dfd/`, le skill Codex installate in `.agents/skills/`. La policy obbligatoria è in [AGENTS.md](../../AGENTS.md); il framework centrale resta il riferimento normativo.

Non modificare le copie gestite in `.dfd/kit/` o le skill installate per sviluppare il toolkit: modificare le sorgenti canoniche in `skills/` e `templates/`, tramite una feature DFD. Le personalizzazioni del dominio vivono in [domains/dfd-kit](domains/dfd-kit/process.md).

Preservare file dell’utente, confini del filesystem, contratti JSON e provenienza delle evidenze. Non eseguire pubblicazioni o comunicazioni esterne senza autorizzazione pertinente. Nessun esito strutturale equivale a una decisione umana.
